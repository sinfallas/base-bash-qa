# base-bash-qa

Código fuente y orquestación para la imagen Docker sinfallas/base-bash-qa. Provee un entorno efímero basado en Ubuntu 26.04 LTS equipado con BATS, ShellCheck, kcov, shfmt y librerías de mocking preconfiguradas para pruebas automatizadas de scripts en Bash.
